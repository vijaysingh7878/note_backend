# 📝 Notes App (MERN Stack)

A simple and modern Notes Management Application built using Node.js + Express.Js + MongoDB.

## 🚀 Features
- User Authentication (Signup/Login with JWT)
- Create, Edit, Delete Notes
- User-specific Notes 
- Protected Routes


## 🛠️ Tech Stack
 
Backend: Node.js, Express, MongoDB, JWT, Bcrypt

## ⚙️ Setup

### Clone
git clone https://github.com/your-username/notes-app.git


### Backend
cd backend
npm install
npm start


## 🔐 API
POST /api/user/signup  
POST /api/user/login  
GET /api/note  
POST /api/note  
PUT /api/note/:id  
DELETE /api/note/:id
